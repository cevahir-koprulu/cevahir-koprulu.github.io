# Cevahir Koprulu — personal website

Published at https://cevahir-koprulu.github.io/ through GitHub Pages from the root of the `main` branch.

The site uses static HTML, CSS, and JavaScript. No build step is required.

- `index.html`: website content
- `style.css`: shared typography, layout, and research-area colors
- `script.js`: enlarged figure viewer
- `assets/`: approved portrait and paper illustrations
- `data/CV_CevahirKoprulu.pdf`: downloadable CV

The previous website is preserved in Git history. A dated ZIP backup is also saved locally in `.local-backups/website-before-redesign-2026-11-06.zip`; this local backup is excluded from publication.
